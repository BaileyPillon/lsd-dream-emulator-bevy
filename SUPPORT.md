# Support

This project is a development preview. There is no stable binary release or
complete replacement for the original game yet. Start with
[project status](docs/STATUS.md) and [the setup guide](docs/GETTING_STARTED.md).

| Need | Where to go |
| --- | --- |
| Build, dependency, or launch help | [Getting started and troubleshooting](docs/GETTING_STARTED.md) |
| A reproducible crash, import failure, or gameplay difference | [Bug report](https://github.com/BaileyPillon/lsd-dream-emulator-bevy/issues/new?template=bug_report.yml) |
| An original-behavior recovery task, analysis tool, or optional mod | [Feature proposal](https://github.com/BaileyPillon/lsd-dream-emulator-bevy/issues/new?template=feature.yml) |
| A suspected security vulnerability | [Private vulnerability reporting](https://github.com/BaileyPillon/lsd-dream-emulator-bevy/security/advisories/new), following [SECURITY.md](SECURITY.md) |
| A code or documentation contribution | [Contributing](CONTRIBUTING.md) |

For a useful report, include the commit, operating system, exact command,
enabled Cargo features, and expected versus observed behavior. For graphics or
audio failures, include the relevant device and driver details. An owned small
fixture or bounded log is more useful than a complete local data dump.

Keep game files, BIOS images, credentials, personal paths, and complete memory
or audio captures out of public reports. The repository does not distribute
original game content; contributors supply their own reference files locally.
