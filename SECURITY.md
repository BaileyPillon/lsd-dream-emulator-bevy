# Security policy

## Supported versions

This project is in early development. Security fixes target the current `main`
branch; there is no supported stable release series yet.

## Report a vulnerability

Use **Security → Report a vulnerability** on this repository for a suspected
security issue. Include the affected revision, platform, minimal reproduction,
and expected versus observed behavior. A small owned malformed-input fixture
is preferable to original game files or a complete memory dump.

Do not include credentials, proprietary game files, BIOS images, or personal
information. Avoid publishing exploit details in a public issue before the
maintainers have had an opportunity to investigate.

Ordinary gameplay differences and build problems belong in the
[bug report form](https://github.com/BaileyPillon/lsd-dream-emulator-bevy/issues/new?template=bug_report.yml).
